# Whisker Scope 🐈

A scope, spectrum and frequency analyzer that had too much catnip at lunch.

Free and open source analyser plugin (VST3) from Studio 87. Early stage: the design mockup is done, the plugin is not built yet.

## What it will do
- Spectrum, Scope, Stereo field and Shapes views
- Mid/Side and L/R analysis, 60 bands at 1/6 octave
- Peak labels with level, frequency and note
- Reference matching: capture a reference, see the EQ difference
- Sidechain layer to compare two signals and show possible masking
- Loudness meters (LUFS)
